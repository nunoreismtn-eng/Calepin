# Calepin · Le français de la pierre

Francês profissional para a pedra natural, ao estilo Pimsleur: o professor diz em português o que queres dizer, respondes em francês em voz alta e ouves a versão nativa.

**Abrir:** https://nunoreismtn-eng.github.io/Calepin/

No Android, abre no Chrome e escolhe **Instalar app** (menu ⋮). No iPhone, Safari → Partilhar → **Adicionar ao ecrã principal**.
